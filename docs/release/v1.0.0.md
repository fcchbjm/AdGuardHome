# v1.0.0 — client_v2 发行、PPv2 UI、upstream 同步与 dnsproxy v0.83.0

标签 **`v1.0.0`** 为 fork 里程碑（非官方 AdGuard Home v1.0）。打 tag 前请完成第三方审查与提交。

## 摘要

**v1.0.0** 起本 fork 发行物切换到新 Web UI 世代，并同步上游与 DNS 运行时：

- 同步 **upstream/master** 至 `369d4761`（含 DoQ 单向流加固、TLS 重构、gopacket DHCP、orval API 生成等）
- **发行嵌入 `client_v2`（SolidJS）**；PPv2 设置已迁入新 UI（设置 → DNS）
- DNS 运行时：**`github.com/fcchbjm/dnsproxy` v0.83.0**

**架构边界：** 本仓库负责打包、发版、Web UI 与更新索引；传输层行为以 dnsproxy 发行说明为准。

## 发行界面（Release UI）

自 **v1.0.0** 起，GitHub Release / GHCR 嵌入 **`client_v2`**。旧 React `client/` 仍保留在源码树中，但不再用于 fork 发行与 CI 默认路径。

**升级会切换到新界面。** YAML 中的 PPv2 字段与后端语义保持兼容。

## 亮点

- **上游同步**：`2961664c..369d4761`（安全/DHCP/TLS/API/Dashboard 等）
- **PPv2 Web UI（client_v2）**：TCP/TLS 开关 + `trusted_proxies` CIDR 列表（设置 → DNS）
- **运行时**：`fcchbjm/dnsproxy@v0.83.0`；Go **1.26.5**
- **发行语义**：模块 `github.com/fcchbjm/AdGuardHome`；Release `version.json`；容器 `ghcr.io/fcchbjm/adguardhome`

## 安全与协议变更

以本次合并的上游 CHANGELOG / GHSA 为准（含 DoQ 资源耗尽相关加固等）。请查阅仓库根目录 `CHANGELOG.md` 中 `[Unreleased]` 与上游 `v0.107.x` 条目。
